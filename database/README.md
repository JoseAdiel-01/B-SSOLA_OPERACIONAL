# Database — Bússola Operacional

Esta pasta contém a documentação e os arquivos relacionados ao banco de dados do projeto.

## Objetivo
Armazenar e organizar os dados coletados pelos sensores da Bússola Operacional.

## Dados monitorados
- Temperatura.
- Umidade.
- Qualidade do ar.
- Nível de som.

## Responsabilidades
- Armazenar informações recebidas pela API.
- Organizar o histórico de medições.
- Permitir consultas dos dados coletados.
- Disponibilizar informações para o sistema de monitoramento.

## Status
Em desenvolvimento.
