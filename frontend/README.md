# Frontend — Bússola Operacional

Esta pasta contém os arquivos relacionados à interface visual do sistema.

## Tecnologias previstas
- HTML5
- CSS3
- JavaScript

## Responsabilidades
- Apresentar os dados coletados pelos sensores.
- Exibir informações ambientais.
- Apresentar o estado atual do monitoramento.
- Exibir alertas identificados pelo sistema.
- Permitir o acompanhamento das condições monitoradas.

## Comunicação

O frontend receberá informações disponibilizadas pelo backend por meio da REST API.
