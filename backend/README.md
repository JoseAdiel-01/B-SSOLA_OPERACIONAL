# Backend — Bússola Operacional

Esta pasta contém os arquivos responsáveis pela comunicação, processamento e gerenciamento dos dados do sistema.

## Tecnologias
- Python 3
- REST API
- Integração com banco de dados

## Responsabilidades
- Receber dados enviados pelo ESP32.
- Processar informações dos sensores.
- Encaminhar dados para armazenamento.
- Disponibilizar informações para o frontend.
- Gerenciar a comunicação entre os componentes do sistema.

## Arquitetura

ESP32 → REST API → Banco de Dados → Frontend
